# 🏎️ Neon Highway X

A real-time neon-themed car racing game built with **Python and Pygame**, featuring AI opponents, dynamic racing mechanics, nitro boosts, collisions, health management, and multiple laps.

## 🎮 Features

* 🏁 Real-time car racing
* ⚡ Automatic acceleration
* 🚀 Nitro boost system
* 🔥 Fast Mode
* 🎯 Booster pickups
* 🤖 AI-controlled opponents
* 🏎️ AI overtaking behavior
* 💥 Real-time collision detection
* ❤️ Player health system
* 🔄 Multiple laps
* ⏱️ 3-minute race duration
* ✨ Particle effects
* 🌃 Neon highway environment
* ⏸️ Pause and restart functionality
* 🏠 Start/menu screen

## 🎮 Controls

| Key     | Action         |
| ------- | -------------- |
| `ENTER` | Start Race     |
| `A / D` | Steer          |
| `← / →` | Steer          |
| `F`     | Fast Mode      |
| `SPACE` | Nitro          |
| `S / ↓` | Brake          |
| `P`     | Pause          |
| `R`     | Restart        |
| `ESC`   | Return to Menu |

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/mahitech580/Neon-Highway-X.git
cd Neon-Highway-X
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the game

```bash
python index.py
```

## 🏁 Gameplay

The player automatically accelerates through a neon highway while competing against AI-controlled cars.

Use steering controls to avoid collisions, collect boosters, activate **Fast Mode**, and use **Nitro** for additional speed.

The race supports multiple laps and runs for a maximum of **3 minutes**. Managing speed, health, collisions, and boosts is essential for completing the race.

## 🤖 AI Opponents

AI opponents are designed to provide dynamic racing behavior, including:

* Lane movement
* Speed management
* Overtaking
* Interaction with the racing environment
* Collision handling

## 💥 Game Systems

### Nitro System

Use `SPACE` to activate the nitro boost and temporarily increase speed.

### Fast Mode

Press `F` to activate Fast Mode for higher-speed gameplay.

### Health System

Collisions affect the player's health. Avoiding traffic and managing movement is important for staying in the race.

### Booster Pickups

Collect boosters placed along the highway to gain gameplay advantages.

### Particle Effects

Visual particle effects enhance collisions, boosts, and other in-game events.
